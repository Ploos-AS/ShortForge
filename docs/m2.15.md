# M2.15 — TikTok publish status

TikTok Direct Post processing is asynchronous. ShortForge now exposes both a single status fetch and bounded polling.

- Endpoint: `/v2/post/publish/status/fetch/`
- Scope: the existing `video.publish` token is sufficient for Direct Post status.
- Terminal outcomes: `PUBLISH_COMPLETE` and `FAILED`.
- Failure results preserve TikTok's `fail_reason`.
- Publicly available post IDs are preserved when TikTok returns them.
- Polling is bounded by `max_attempts`; ShortForge never waits indefinitely.
- The polling interval has a 2-second minimum, matching TikTok's documented 30 requests/minute per-token status limit.

Processing/moderation has no guaranteed completion time, so a non-terminal bounded poll is a valid result rather than an error. Webhooks are the natural later complement for long-running publication state.
