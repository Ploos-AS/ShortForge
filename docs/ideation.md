# Ideation and variants

ShortForge should spend tokens before it spends render compute.

## Funnel

1. One premise.
2. Generate diverse hook/angle combinations.
3. Reject duplicates and weak hooks.
4. Expand survivors into timed beat plans.
5. Structural score.
6. Comedy/editor review.
7. Render only the best few.
8. Produce platform-specific cuts from selected material.

## Diversity rule

Variants must change the comedic mechanism or narrative angle, not merely paraphrase the opening sentence.

## Review roles

- Hook critic
- Clarity critic
- Comedy editor
- Pacing/retention critic
- Payoff critic
- Loop critic
- Production-feasibility critic

Automated scores are advisory. Real audience metrics can later be imported as a separate feedback signal without rewriting historical scores.
