# M2.6 — Publishing package

A rendered ShortForge workspace can now be converted into a self-contained delivery package.

```sh
shortforge package build/my-short --title "My short"
```

The package is only produced after the rendered MP4 passes the M2.4 ffprobe qualification gate.

Contents:

- `short.mp4` — qualified delivery master
- `thumbnail.png` — frame extracted from the encoded master
- `captions.json` — timed caption assets
- `metadata.json` — title, profile, duration and format
- `manifest.json` — source asset manifest
- `render-plan.json` — deterministic render provenance
- `qualification.json` — end-product QA result
- `package.json` — package contract and inventory

M2.6 deliberately stops before uploading to any social platform. Platform publishers can consume this stable package contract in later milestones.
