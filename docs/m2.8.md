# M2.8 — YouTube publisher

The YouTube publisher consumes a qualified M2.6 publishing package.

Dry run:

```sh
shortforge publish youtube build/my-short/publish --privacy private --dry-run
```

Network upload requires an OAuth access token supplied at invocation time. ShortForge does not persist the token.

The implementation uses YouTube Data API v3 `videos.insert` with `uploadType=resumable`. The initial milestone requests the least-privilege `youtube.upload` scope for video upload. Caption upload is deliberately separated because the YouTube captions API requires a stronger scope (`youtube.force-ssl`). Custom thumbnail and captions are staged as follow-up operations after the core video upload contract is qualified.

Privacy defaults to `private`. Note that YouTube may restrict uploads from unverified API projects to private viewing until the API project passes Google's required audit.

CI uses dry-run/mocked transport only and never requires Google credentials.
