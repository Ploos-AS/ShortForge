# M2.2 — FFmpeg assembly

M2.2 introduces the deterministic render boundary.

`shortforge render WORKSPACE --plan-only` writes `render-plan.json` without requiring FFmpeg. The plan contains the exact argv used for rendering and is suitable for CI qualification and inspection.

`shortforge render WORKSPACE` executes that plan with the system FFmpeg and produces `output/short.mp4`.

The initial assembler concatenates ready visual assets according to manifest timing, normalizes them to 1080x1920 at 30 fps, encodes H.264/yuv420p and enables fast-start metadata.

Audio mixing and burned/styled captions are intentionally deferred to the next assembly increment. M2.2 establishes a real playable MP4 path while keeping the render plan independently testable.
