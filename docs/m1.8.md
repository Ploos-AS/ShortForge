# M1.8 — Script and storyboard expansion

M1.8 introduces the first production-document stage.

A selected concept variant can be expanded into a `ShortForgeStoryboard` containing a vertical format, target duration, timed beats, voice-over, captions, shot intent, asset prompts and an explicit loop instruction.

```sh
shortforge generate "Commodore launches Amiga 9000" --profile retro > variants.yaml
shortforge select variants.yaml
shortforge expand variants.yaml --index 0 --profile retro > storyboard.yaml
```

The initial expansion provider is deterministic so the complete path remains reproducible and CI-safe. Later AI expansion providers can target the same storyboard contract.

M1.8 deliberately stops before rendering media. Its output is a production plan suitable for later image, video, voice and editing stages.
