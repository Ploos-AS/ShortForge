# M2.11 — Publishing UX and authentication

ShortForge no longer accepts YouTube bearer tokens as command-line arguments.

## Authentication

Normal YouTube video and thumbnail publishing reads `SHORTFORGE_YOUTUBE_ACCESS_TOKEN`.
Optional caption publishing reads `SHORTFORGE_YOUTUBE_CAPTION_ACCESS_TOKEN`, keeping the stronger `youtube.force-ssl` credential separate from the normal `youtube.upload` credential.

Tokens are resolved at execution time and are not written to publishing packages or result files.

## Unified publishing

`shortforge publish youtube PACKAGE --upload-captions --caption-language no --result-file result.json`

performs the qualified video upload, custom thumbnail upload and optional SRT caption upload, returning one `ShortForgePublishResult` containing the video ID, URL, thumbnail status and caption result.

`--dry-run` requires no credentials and performs no network operation.
