# M2.4 — Render qualification

M2.4 qualifies the rendered artifact, not merely the render plan.

The CI pipeline now builds a real deterministic fixture video with FFmpeg and inspects it with ffprobe. Qualification requires:

- H.264 video
- 1080x1920 frame size
- 30 fps average frame rate
- AAC audio
- expected duration within 0.25 seconds

The same gate is exposed locally:

```sh
shortforge qualify-render output/short.mp4 --duration 20
```

The command emits structured JSON and exits non-zero when qualification fails.
