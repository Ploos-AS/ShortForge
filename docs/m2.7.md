# M2.7 — Publisher contracts

ShortForge now separates package production from publication.

Publisher capability discovery:

```sh
shortforge publishers
```

Registered contracts:

- `filesystem` — implemented, deterministic, offline, no authentication
- `youtube` — network/auth contract registered; implementation intentionally deferred
- `tiktok` — network/auth contract registered; implementation intentionally deferred
- `instagram` — network/auth contract registered; implementation intentionally deferred

Offline qualification:

```sh
shortforge publish filesystem build/my-short/publish --destination deliveries/my-short
```

Every publisher must consume a complete `ShortForgePublishingPackage` whose `qualified` flag is true. This prevents platform adapters from bypassing render/package QA.

M2.7 contains no credentials, OAuth flow or platform network requests.
