# M2.14 — TikTok publisher qualification

ShortForge Direct Post follows TikTok's current Content Posting API flow.

1. Query `/v2/post/publish/creator_info/query/` with the `video.publish` user token.
2. Require the requested privacy level to be present in the creator's current `privacy_level_options`.
3. Reject a package whose declared duration exceeds `max_video_post_duration_sec` when TikTok supplies that capability.
4. Initialize `/v2/post/publish/video/init/` using `FILE_UPLOAD`.
5. PUT the local MP4 to TikTok's returned upload URL using `Content-Range`.
6. Return the `publish_id`; processing/moderation is asynchronous.

Unaudited TikTok clients are restricted to private viewing. ShortForge therefore keeps `SELF_ONLY` as the default and never assumes public posting is available.

CI uses mocked HTTP only and never requires TikTok credentials.
