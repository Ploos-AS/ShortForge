# M2.0 — Media workspace

M2 begins physical media production with a deterministic, offline workspace backend.

`shortforge materialize assets.yaml build/my-short/` creates:

- `workspace.json` — materialization state and paths
- `manifest.json` — immutable input snapshot
- `captions/*.txt` — immediately usable text assets
- `assets/*.json` — deterministic placeholder requests for visual/audio assets

Placeholder files preserve the complete provider-neutral request. Future providers replace or resolve them with generated media while retaining stable asset IDs.

Asset IDs are validated before being used as filenames; traversal-style IDs are rejected.

M2.0 intentionally performs no network calls and creates no synthetic binary media. It establishes the reproducible filesystem boundary for later generators and rendering.
