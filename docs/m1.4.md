# M1.4 — Provider abstraction

M1.4 introduces provider-neutral concept generation.

The core contract is `Provider.generate_variants(GenerationRequest)`, which returns the existing `ShortForgeVariantSet` format. Selection therefore does not need to know whether candidates came from a cloud LLM, a local model or an offline test provider.

## Deterministic provider

The first provider is deliberately offline and deterministic. It exists to qualify the contract in CI without credentials, network access, model drift or provider cost.

```sh
shortforge generate "Amiga 9000 launch" --count 5
```

Real providers will be adapters behind the same interface. Provider-specific SDK objects and response formats must not leak into the ShortForge project/variant schema.
