# M1.5 — OpenAI-compatible provider

M1.5 adds the first network-capable provider while preserving the M1.4 contract.

`openai-compatible` targets the widely implemented `/v1/chat/completions` shape and requests JSON output. Base URL, API key and model are configuration, so the adapter is not tied to one hosted service.

Environment:

```sh
export SHORTFORGE_OPENAI_BASE_URL=https://api.openai.com/v1
export SHORTFORGE_OPENAI_API_KEY=...
export SHORTFORGE_OPENAI_MODEL=...
shortforge generate "Amiga 9000 launch" --provider openai-compatible --count 5
```

CI never calls an external model. Its transport is injected with fixtures and tests request construction, JSON parsing, variant-count enforcement and malformed-response rejection.

The deterministic provider remains the default and qualification baseline.
