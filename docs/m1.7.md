# M1.7 — Generation profiles and prompt contracts

M1.7 makes creative intent explicit and provider-neutral.

Profiles define tone, audience, target duration and generation requirements. The initial catalog is: `default`, `comedy`, `retro`, `educational`, `news-parody`, and `product-demo`.

```sh
shortforge profiles
shortforge generate "Commodore launches a new Amiga" --profile retro --count 5
```

The selected profile is recorded in the generated `ShortForgeVariantSet`. Network providers receive the same normalized profile contract, while the deterministic provider validates and records it for offline qualification.

Profiles describe creative constraints; they do not predict platform performance or virality.
