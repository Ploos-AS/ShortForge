# M2.16 — Instagram Reels publisher

ShortForge now implements the Reels container publishing flow while keeping media staging explicit.

1. Require an absolute HTTPS `video_url`; Instagram fetches the media remotely.
2. Create a `REELS` media container for the Instagram professional account.
3. Poll `status_code` until `FINISHED`; reject `ERROR` and `EXPIRED` and use a bounded polling budget.
4. Call `media_publish` exactly once after the container is ready.
5. Preserve both the transient container ID and permanent media ID in the result.

The qualified ShortForge package remains local and credential-free. A staging/CDN layer must expose the MP4 over HTTPS before live Instagram publishing. CI uses mocked HTTP only.

The Graph API version defaults to `v25.0` and can be overridden with `SHORTFORGE_INSTAGRAM_GRAPH_VERSION`, avoiding a hard dependency on one API generation.
