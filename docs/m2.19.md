# M2.19 — OCI publishing

Release tags matching `vMAJOR.MINOR.PATCH` publish the qualified ShortForge OCI runtime as a multi-architecture image for `linux/amd64` and `linux/arm64`.

GHCR publishing uses the repository `GITHUB_TOKEN` and creates immutable/exact plus convenience aliases: `vMAJOR.MINOR.PATCH`, `vMAJOR.MINOR`, `vMAJOR`, and `latest`.

Docker Hub is optional. When both `DOCKERHUB_USERNAME` and `DOCKERHUB_TOKEN` repository secrets exist, the same multi-arch manifest is copied to `<username>/shortforge` with the same aliases. Missing Docker Hub credentials do not block GHCR releases.

The workflow rejects non-semver manual release refs so `latest` cannot be accidentally replaced by an arbitrary branch build.
