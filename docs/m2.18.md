# M2.18 — OCI runtime

ShortForge ships as an Alpine-based OCI runtime with the CLI, Python runtime, FFmpeg and DejaVu fonts in one reproducible image.

The image uses `python:3.13-alpine`, following the Ploos Alpine-first policy. CI does not accept a build-only container: it runs ShortForge CLI smoke tests and performs a real deterministic media resolution, FFmpeg render and ffprobe qualification inside the image.

The working directory is `/work`; mount project/workspace data there. The default entrypoint is `shortforge`.

If Alpine/musl or Alpine's FFmpeg package later causes a demonstrated compatibility problem, Debian slim is the documented fallback rather than an assumed requirement.
