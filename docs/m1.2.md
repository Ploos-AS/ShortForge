# M1.2 — Selection pipeline

M1.2 adds deterministic candidate ranking before expensive media generation.

```text
idea -> variants -> structural scoring -> ranking -> selected candidate
```

Use:

```sh
shortforge select examples/retro-gag/variants.yaml
```

The selector scores hook, angle, payoff and completeness, then ranks candidates with deterministic tie-breaking. The output includes the selected candidate, per-dimension scores and concise reasons.

This is deliberately a **structural heuristic**, not a virality predictor. Later milestones may add provider-backed semantic review, platform adapters and learned/experimental signals while preserving this provider-neutral selection contract.
