# M2.12 — Render hardening

M2.12 strengthens deterministic production rendering without changing the asset contract.

- Visual inputs use aspect-preserving scale-to-fill plus center crop instead of stretching.
- Render output is resolved and must remain inside the workspace.
- Every audio input is normalized to 48 kHz stereo before delay, gain and mixing.
- The render plan records audio sample-rate/channel invariants for qualification and debugging.

These rules apply to all production profiles.
