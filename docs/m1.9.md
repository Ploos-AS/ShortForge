# M1.9 — Asset manifest and media provider contracts

M1.9 compiles a storyboard into a deterministic `ShortForgeAssetManifest`.

Each storyboard beat produces stable visual, voice and caption asset IDs. The manifest also declares optional music and SFX beds. Assets carry timing and generation inputs but not provider-specific SDK data.

```sh
shortforge assets storyboard.yaml > assets.yaml
shortforge media-contracts
```

Initial provider contracts cover visual generation, voice/TTS, music, SFX and captions. Generated media is referenced by URI and MIME type; binary media is not embedded in project YAML.

This separates creative planning from media generation and allows local or hosted providers to implement the same contracts.
