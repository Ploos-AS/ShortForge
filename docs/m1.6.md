# M1.6 — Native OpenAI Responses provider

M1.6 separates native OpenAI support from the generic chat-completions compatibility adapter.

`openai-responses` sends generation requests to the Responses API and parses `output_text` content into the existing `ShortForgeVariantSet` contract. The adapter remains transport-injectable so CI is offline.

Provider metadata also exposes network, credential and protocol capabilities. CLI introspection can therefore describe providers without reading or printing secret values.

The deterministic provider remains the default.
