# M2.17 — Provider-neutral media staging

Instagram fetches Reel media from an HTTPS URL, while a qualified ShortForge package contains a local MP4. M2.17 introduces a staging boundary between those concerns.

## Contracts

- `filesystem`: deterministic/offline qualification adapter. It copies the media, records byte size and SHA-256, and deliberately returns no public URL.
- `https-url`: adapter for a URL produced by an external staging service. It requires absolute HTTPS and rejects an already expired URL.

A future S3, Cloudflare R2, MinIO gateway or other object-store adapter can implement the same `MediaStager` interface without changing the Instagram publisher or qualified package format.

Staging credentials and signed URLs are runtime data. They are not written into the publishing package.
