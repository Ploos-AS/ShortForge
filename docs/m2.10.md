# M2.10 — YouTube captions

ShortForge can upload its deterministic timed SRT sidecar as a YouTube caption track.

- endpoint: `captions.insert` media upload with `part=snippet`
- transport: `multipart/related` metadata + SRT media
- required metadata: video ID, BCP-47 language tag, track name
- authorization: separate OAuth token carrying `youtube.force-ssl`
- maximum caption payload: 100 MB
- deprecated YouTube `sync` is not used; ShortForge supplies its own timecodes
- normal video+thumbnail publishing remains on the narrower `youtube.upload` scope

CI uses a mocked HTTP transport and never contacts YouTube or stores credentials.
