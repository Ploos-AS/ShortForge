# M2.1 — Deterministic media resolver

M2.1 resolves workspace placeholders into real, valid media files without network access or external binaries.

```sh
shortforge resolve build/my-short/
```

The deterministic backend currently creates:

- 360x640 RGB PNG files for visual assets
- 16 kHz mono PCM WAV silence for voice, music and SFX assets
- captions remain the text files materialized in M2.0

Resolved workspace records change from `placeholder` to `ready` and record MIME type plus provider provenance.

The files are intentionally synthetic fixtures, not creative output. Their purpose is to make the entire production and future FFmpeg assembly path executable and testable offline before real AI/TTS/media providers are added.
