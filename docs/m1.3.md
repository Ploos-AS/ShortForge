# M1.3 — CI and qualification

M1.3 establishes the first automated quality gate for ShortForge.

## Qualification matrix

- Python 3.11
- Python 3.12
- Python 3.13

Each job installs ShortForge from `pyproject.toml`, runs the unit tests and exercises the installed `shortforge` command against the checked-in retro-gag examples.

## Required smoke path

```text
validate project
 -> score project
 -> inspect variants
 -> select candidate
```

This deliberately qualifies the installed package rather than only importing source files from the checkout. Provider-backed generation and rendering remain outside this milestone.
